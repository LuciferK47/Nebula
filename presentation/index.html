Why MemTier-MoE Outperforms Existing Baselines

01 • Activation vs Weight Transfer
Hybrid SOTA Routing

Two-tier weight transfer moves 17.2 MB per expert layer over PCIe, thrashing the cache and saturating bandwidth (13.4 GB total). Hybrid mode sends activations (only ~8 KB per token) to CPU-resident experts, slashing bus volume by 1,944× and eliminating cache evictions entirely.

02 • Predictive Prefetch Gating
Adaptive Threshold Filtering

When weight transfer is required, Lookahead prefetching anticipates upcoming layer activations using Markovian co-occurrence. Gating with τ = 0.15 cuts unnecessary evictions from 1,131 to 778, saving 6GB of speculative memory bus movement.

03 • 3-Tier CXL Coherency
Heterogeneous Capacity Expansion

Tier-3 CXL memory expands host capacity beyond physical DIMM limits with 350ns memory-side bus simulation. Low-frequency tail experts reside safely in CXL with zero impact on hot HBM cache residency.
